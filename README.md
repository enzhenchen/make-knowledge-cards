# make-knowledge-cards

## 1. 项目解决什么问题

文章中的重要知识常常与重复表述、案例和宣传内容混在一起，不方便复习。本项目帮助 Codex 从原文中提取重要、独立的知识点，整理成便于理解和复习的 Markdown 卡片。

这是给 Codex 使用的指令型 Skill，由模型按照规则完成提炼；项目不提供独立转换程序、命令行工具或图形界面。

## 2. 主要功能

- 接受粘贴的正文，以及本地 `.md`、`.markdown`、`.txt` 文件，扩展名不区分大小写。
- 通常生成 **5～8 张**卡片；信息不足时少做，甚至输出 0 张，不拆句或扩写凑数。
- 每张只讲一个知识点，包含标题、核心知识、简明解释、原文例子或自测问题，并附原文依据。
- 合并重复知识，删除广告、寒暄和次要细节；不添加原文没有的信息。
- 没有原文例子时，使用可由本卡回答的自测问题，并提供参考答案。
- 保留原文的条件、数字、不确定性和观点归属；默认在对话中输出 Markdown，用户要求时可保存为文件。

暂不支持网页抓取、PDF、Anki 导出或图形界面。

## 3. 安装方法

需要能够加载 Skill 的 Codex；读取或保存本地文件时，还需要 Codex 对相应路径有访问权限。Skill 本身没有运行脚本，无需安装 Python、Node.js 或第三方库。

下载并解压本项目后，在项目根目录执行以下命令（macOS/Linux）：

```sh
mkdir -p "$HOME/.agents/skills"
cp -Ri make-knowledge-cards "$HOME/.agents/skills/"
```

如果已有同名 Skill，`cp -i` 会在覆盖文件前询问。也可以手动把整个 `make-knowledge-cards/` 文件夹复制到 `~/.agents/skills/`。Windows 可手动复制到用户主目录下的 `.agents/skills/`。

安装后的结构应为：

```text
~/.agents/skills/make-knowledge-cards/
├── SKILL.md
└── agents/
    └── openai.yaml
```

按 [Codex 官方技能文档](https://developers.openai.com/codex/skills)，个人技能目录为 `~/.agents/skills/`，技能变更会自动检测；若未显示，可重启 Codex。安装只需要上述 Skill 文件夹，不必复制 README 或测试材料。

## 4. 使用方法

**粘贴文章**：在 Codex 对话中显式调用 Skill，并附上正文。

```text
请使用 $make-knowledge-cards，把下面的文章整理成知识卡片：
（粘贴文章正文）
```

**读取本地文件**：提供真实文件路径，Markdown 和 TXT 均可。

```text
请使用 $make-knowledge-cards，读取 /绝对路径/文章.md 并制作知识卡片。
```

**保存结果**：在请求中另行指定输出路径。

```text
请使用 $make-knowledge-cards，读取 /绝对路径/文章.txt，
把知识卡片保存到 /绝对路径/知识卡片.md，不要覆盖原文。
```

示例路径需要替换为自己的路径。默认只在对话中回复，不自动创建输出文件。

**在项目内试用**：不安装也可以打开本项目，让 Codex 读取规则后处理测试文件。

```text
请读取 make-knowledge-cards/SKILL.md 并按其中规则，
把 tests/inputs/technical.md 整理成知识卡片。
```

## 5. 输入输出示例

### 原文有例子

输入：

```text
恢复演练用于确认备份能否实际恢复。例如，取一份备份恢复到测试目录，再检查文件能否打开。
```

输出：

```markdown
来源：粘贴文本；共 1 张卡片。原文仅有一个独立知识点，不凑足 5 张。

### 1. 恢复演练检查备份可用性
- **核心知识**：恢复演练用于确认备份能否实际恢复。
- **简明解释**：本文通过执行恢复并检查文件能否打开，来检验备份能否恢复。
- **例子**：取一份备份恢复到测试目录，再检查文件能否打开。
- **原文依据**：第 1 段：“恢复演练用于确认备份能否实际恢复。”同段给出上述例子。
```

### 原文没有例子

输入：

```text
随机分组有助于减少分组造成的系统差异，但不保证每次分组后两组完全相同。
```

输出：

```markdown
来源：粘贴文本；共 1 张卡片。原文仅有一个独立知识点，不凑足 5 张。

### 1. 随机分组不保证两组完全相同
- **核心知识**：随机分组有助于减少分组造成的系统差异，但不保证两组完全相同。
- **简明解释**：减少差异与保证完全一致是不同的结论，原文只支持前者。
- **自测问题**：随机分组后能否假定两组必然完全相同？
  **参考答案**：不能。
- **原文依据**：第 1 段：“随机分组有助于减少分组造成的系统差异，但不保证每次分组后两组完全相同。”
```

以上展示输出格式，实际措辞和数量由原文决定。只有情绪表达、广告或寒暄而没有实质知识时，Skill 会说明原因并输出 0 张卡片。

## 开发与测试

Skill 使用 Codex 自带的 `skill-creator/scripts/init_skill.py` 初始化，仅包含 `SKILL.md` 和 `agents/openai.yaml`。测试材料放在技能目录之外，无需随 Skill 安装。

已手动测试技术说明、科普、观点、重复文本及无实质知识文本，分别输出 6、5、3、2、0 张卡片，并据结果补充观点归属和个案局限规则。原始输入、实际输出、复现方法及测试限制见 [测试记录](tests/results.md)。官方 `quick_validate.py` 结构验证已通过；该验证不代表内容质量保证。
